### US-001: 悬停节点或边查看其配置
- 故事：As a 集成开发者, I want to 把鼠标放到编排图的节点或边上就看到它的配置摘要, so that 我不用翻表单就能核对这个 agent / 节点到底配成了什么。
- 关联需求：REQ-FUNC-001、REQ-NFUNC-009、REQ-NFUNC-011；优先级：Must Have；故事点：5 [ESTIMATE]
- AC-001-01：Given 项目含默认专家 kb-agent（中文标签"知识库助手"，已授权工具 1 个，主提示词存在）/ When 鼠标悬停在该专家节点上 / Then 出现卡片，包含：中文标签"知识库助手"、name "kb-agent"、"默认专家"标记、已授权工具名列表、"主提示词：存在"及主提示词前 120 个字符；卡片在 300 毫秒内出现（`[INFERRED]` 阈值，校准前未验收）
- AC-001-02：Given 编排图含 route 节点 / When 悬停该节点 / Then 卡片显示 tau、margin、max_expert_steps、default_expert 四项的当前值，且与"路由参数"表单中的值相同
- AC-001-03：Given 某专家没有任何工具授权，且系统已配置 LLM Key / When 悬停该专家节点 / Then "已授权工具"一行显示"无"（而非空白），卡片及其数据来源响应中不出现任何凭据值
- AC-001-04：Given 鼠标悬停在条件边上 / When 查看卡片 / Then 卡片显示"条件边"、各分支键及其目标节点名、"否则"分支的目标
